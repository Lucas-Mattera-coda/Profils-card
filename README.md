# Carte de profil utilisateur

**Durée** : 60 minutes — En binôme

**Objectif** : Créer une carte de profil avec photo, nom, bio, et statistiques en utilisant les concepts vus en cours (sémantique HTML, modèle de boîte, sélecteurs, pseudo-classes, pseudo-éléments, tableaux, unités relatives).

## Consignes

1. **Structure sémantique** : Utiliser les balises sémantiques et régions appropriées.
2. **Modèle de boîte** : Donner la carte un "rembourrage" intérieur, une bordure arrondie, et une ombre portée.
3. **Dimensions flexibles** : Fixer la largeur de la carte et la centrer horizontalement.
4. **Image circulaire** : Rendre l'image de profil circulaire.
5. **Pseudo-classes** : Stylisez les liens focalisés et au survol de la souris (appliquer le même style aux deux pour l'accessibilité).
6. **Pseudo-éléments** : Sur le nom, apposer un badge "En ligne" (petit cercle vert) à l'aide d'un pseudo-élément approprié.
7. **Tableau** : Créez un tableau des statistiques (projets, followers, following) respectant les règles d'accessibilité.
8. **Unités relatives** : Utilisez des unités relatives pour toutes les tailles de police et espacements.

## Consignes bonus

1. Tableau des badges du cours de HTML (Image du badge, nom du badge, date d'obtention, niveau (bronze, argent, or, diamant), secret)
2. Le site est publié via github pages
